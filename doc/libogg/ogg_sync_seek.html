ogg_sync_seek

declared in "ogg/ogg.h";

This function repositions a seekable datasource so that decoding of one logical bitstream can resume at the first packet whose ending granule position is greater than or equal to a requested target. It is the primitive needed to implement "scrubbing" (drag-to-seek) in a player.

The caller supplies read/seek/tell callbacks for the datasource along with the serial number of the logical stream and the target granule position. The function performs a bisection search over the datasource, so the amount of data read grows logarithmically with the file length. Multiplexed (interleaved) logical streams, chained segments, pages that carry no ending granule position and packets spanning multiple pages are all handled.

On success the datasource is left positioned at the beginning of the page carrying the most recent known granule position before the target (or at the first page of the stream if there is none), the ogg_sync_state is reset and ready to be refilled, and the ogg_stream_state (if given) is reset so that continued decoding does not report a hole at the seek point. Decoding simply continues with the usual ogg_sync_buffer / ogg_sync_wrote / ogg_sync_pageout / ogg_stream_pagein / ogg_stream_packetout loop. 


int ogg_sync_seek(ogg_sync_state *oy, ogg_stream_state *os,
                  long serialno, ogg_int64_t target,
                  const ogg_seek_callbacks *cb, void *datasource);

Parameters

oy
Pointer to an initialized ogg_sync_state struct. It is used during the search and is left reset on return.
os
Pointer to the ogg_stream_state of the logical stream being sought, or NULL. If non-NULL it is reset on a successful seek so that no spurious data gap is reported; it must belong to serialno.
serialno
Serial number of the logical bitstream to seek within.
target
Target granule position. Decoding will resume such that the first packet ending at or after this position is produced.
cb
Pointer to an ogg_seek_callbacks struct supplying read, seek and tell primitives for the datasource: 
typedef struct {
  size_t      (*read_func)(void *ptr, size_t size, void *datasource);
  int         (*seek_func)(void *datasource, ogg_int64_t offset, int whence);
  ogg_int64_t (*tell_func)(void *datasource);
} ogg_seek_callbacks;
read_func reads up to size bytes and returns the number of bytes read (0 at end of data). seek_func repositions the datasource; whence is one of OGG_SEEK_SET, OGG_SEEK_CUR or OGG_SEEK_END (mirroring SEEK_SET/SEEK_CUR/SEEK_END) and the return value is zero on success. tell_func returns the current absolute offset.
datasource
Opaque pointer passed through to the callbacks.

Return Values

  • OGG_SEEK_OK (0): success; the datasource is positioned and decoding may continue.
  • OGG_SEEK_EINVAL: invalid argument (NULL state or callbacks, negative target).
  • OGG_SEEK_EREAD: a read from the datasource failed.
  • OGG_SEEK_ENOSEEK: the datasource is not seekable.
  • OGG_SEEK_ENOSTREAM: no logical stream with the requested serial number exists.
  • OGG_SEEK_ERANGE: the target granule position lies beyond the end of the stream.

    • On failure the datasource position is restored to where it was before the call.

    Example Usage

    static size_t io_read(void *ptr, size_t size, void *d){
  return fread(ptr, 1, size, (FILE *)d);
}
static int io_seek(void *d, ogg_int64_t off, int whence){
  return fseek((FILE *)d, (long)off, whence); /* OGG_SEEK_* match SEEK_* */
}
static ogg_int64_t io_tell(void *d){
  return (ogg_int64_t)ftell((FILE *)d);
}

  ogg_seek_callbacks cb = { io_read, io_seek, io_tell };
  if(ogg_sync_seek(&oy, &os, serialno, target_granule, &cb, fp) == OGG_SEEK_OK){
    /* continue the normal decode loop from here */
  }
